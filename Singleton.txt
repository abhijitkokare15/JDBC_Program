 # Lecture No : 1
The singleton pattern is implemented by creating a class with a method that creates a new instance of the class if one does not exist. 

If an instance already exists, it simply returns a reference to that object. 

To make sure that the object cannot be instantiated any other way, the constructor is made private.

A thread-safe singleton class is to make the global access method synchronized. 
Using this concept, a single thread can execute this method at a time. 
If you want huge amount of work to be done using getInstance method then,
 it will decreased your system performance by factor of 100. 
To solve this problem we can use "double checked locking".

Double check locking is used to ensure that only one instance of singleton class is created.
